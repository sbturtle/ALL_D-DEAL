## 목표

`docs/plans/completed/`에 보관된 모든 Markdown 계획 문서의 설명·제목·표를 한국어로 통일해, 현재 작업 규칙과 과거 계획 기록을 같은 언어 기준으로 읽을 수 있게 한다.

## 범위와 결정

1. 대상은 `docs/plans/completed/*.md` 전체와 해당 폴더의 README다.
2. 코드 식별자, 파일 경로, 명령어, 카테고리 ID, API·IndexedDB 이름, 커밋 해시와 필요한 표준 기술명은 동작 추적을 위해 원문을 유지할 수 있다.
3. 그 외 영어로 작성된 설명 문장, 제목, 표 머리글, 상태 설명과 검증 메모는 한국어로 번역한다.
4. 계획의 단계 번호, 완료 조건, 범위와 검증 결과는 번역 과정에서 의미와 사실을 바꾸지 않는다.
5. 금융 데이터나 소스 코드는 열거나 수정하지 않으며, 문서 파일만 변경한다.

## 완료 조건

1. 완료 보관 문서 8개를 모두 점검하고 한국어 설명으로 통일한다.
2. 영문 설명 문장이 남아 있는지 검색하고, 허용된 기술 식별자만 예외로 확인한다.
3. `git diff --check`와 문서 구조 점검을 통과한다.
4. 계획 보관, 문서 번역, 완료 기록을 기능 단위 커밋으로 남긴다.
